# 📝 TaskList — Менеджер задач

Менеджер задач для мобильных устройств, созданный с использованием:
- **Flutter, Dart** — frontend
- **Flask, Python** — backend

🔔 **Особенность**: интеграция с Telegram-ботом для получения уведомлений о дедлайнах.

## 📥 Установка

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/SebrianFoxy/TaskList.git
cd TaskList
```
### 2. Установите зависимости
#### Frontend (Flutter/Dart):
```bash
cd frontend/task_list
flutter pub get
```

#### Backend (Python/Flask):
```bash
cd backend
pip install -r requirements.txt
```
### 3. В .env (backend/database) файл добавьте ваши данные для корректной работы
![env file](https://sun9-75.userapi.com/s/v1/if2/UxU1rT_QgNtptIyt5EZhoZQmz8JvYwQzfu-MWVbRAIQZAudP4E1hHaZb-_uGQrZmkc_fBZlI8Wrd7YSZiAmzN8N3.jpg?quality=95&as=32x18,48x27,72x40,108x60,160x88,240x133,360x199,480x265,540x298,640x354,720x398,1080x597,1184x654&from=bu&cs=1184x0)
### 4. Запуск проекта:
Backend:
```bash
cd backend
python3 backend_runner.py
```
Frontend:
```bash
cd frontend/task_lsit
flutter run
```
